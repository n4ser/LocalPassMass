پسوردها کجا هستند؟

LocalPassMass اطلاعات ورود را برای ذخیره یا Sync به هیچ سروری ارسال نمی‌کند. Vault رمزگذاری‌شده داخل فضای محلی Chrome شما نگه‌داری می‌شود.

Backup ضروری است

اگر پروفایل Chrome یا Windows از بین برود، ممکن است Vault هم از دست برود. فایل .svault و Recovery Key را جدا از هم و در دو محل امن نگه دارید.

Autofill امن‌تر

پیشنهاد ورود فقط برای دامنه مرتبط نشان داده می‌شود. Subdomainهای همان سایت پشتیبانی می‌شوند و Autofill روی HTTP به‌صورت پیش‌فرض خاموش است.

قفل با Windows

وقتی صفحه Windows قفل شود، Vault هم خودکار قفل می‌شود تا کلید بازشده در Session باقی نماند.

مجوزها فقط هنگام نیاز

LocalPassMass هنگام نصب دسترسی همه سایت‌ها، Clipboard یا Bridge را نمی‌گیرد. هرکدام فقط وقتی خودتان قابلیت مربوط را فعال کنید درخواست می‌شود.

اگر رمز اصلی را فراموش کنم؟

در صفحه قفل، Recovery Key را انتخاب کنید و رمز اصلی جدید بسازید. بدون Master Password و Recovery Key هیچ Backdoorی وجود ندارد.

Auto Backup محلی

چند Snapshot رمزگذاری‌شده داخل همان Chrome نگه داشته می‌شود تا تغییر یا حذف اشتباه قابل برگشت باشد. این Snapshotها جای Backup خارجی روی هارد را نمی‌گیرند.

استفاده در چند Chrome Profile

در Profile اول از تنظیمات ← تنظیمات پیشرفته، Vault مشترک را فعال کنید. اگر Windows Helper آماده نباشد، LocalPassMass با یک دکمه فایل راه‌انداز را روی Desktop می‌سازد؛ فایل را یک‌بار اجرا کنید و Chrome را Restart کنید. در Profileهای بعدی همان افزونه را نصب و از همان بخش گزینه اتصال را بزنید؛ فقط Master Password لازم است.

لینک‌های وب در تنظیمات فقط با کلیک شما باز می‌شوند؛ خود Vault هیچ داده‌ای به آن صفحات ارسال نمی‌کند.
