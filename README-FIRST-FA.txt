LocalPassMass v1.10.4 — شروع سریع

نصب جدید:
1) ZIP را Extract کنید.
2) در Chrome به chrome://extensions بروید و Developer mode را روشن کنید.
3) Load unpacked را بزنید و فقط پوشه localpass-extension را انتخاب کنید.
4) Vault را بسازید و Recovery Key را در جای امن ذخیره کنید.
5) بعد از Setup، LocalPassMass یک Checklist کوتاه برای فعال‌کردن دسترسی سایت‌ها نشان می‌دهد. بدون این دسترسی Autofill و پیشنهاد Save داخل سایت کار نمی‌کند.

آپدیت:
- افزونه قبلی را Remove نکنید؛ اول Backup بگیرید، فایل‌های localpass-extension را Replace کنید و در chrome://extensions فقط Reload بزنید.

مهم‌ترین تغییرهای v1.10.4:
- آیکون L برای هر فیلد Password به‌صورت پایدار کنار همان فیلد نمایش داده می‌شود.
- اگر برای سایت حساب ذخیره شده باشد، پیشنهاد ورود خودکار نمایش داده می‌شود و از منوی L می‌توانید Fill یا نمایش/مخفی‌کردن رمز را انجام دهید.
- منوی L همیشه Password Generator را دارد؛ اگر حسابی برای سایت ذخیره نشده باشد، منو فقط Generator را نشان می‌دهد.
- تشخیص فیلدهای پرداخت (CVV/CVC/CVV2/رمز پویا/رمز دوم کارت) و حذف آن‌ها از مسیر Password Manager.
- مسیر «ذخیره امن» مقاوم‌تر و قابل Retry شده است.
- Popup روی سایت دارای حساب، به‌طور پیش‌فرض فقط همان حساب‌ها را نشان می‌دهد و دکمه «نمایش همه» دارد.
- Generator روی فرم ساخت حساب، حتی برای فرم‌های تک‌فیلد Password بهتر پیشنهاد می‌شود.

- تشخیص Mobile/Phone/Email/Username و Loginهای SPA/Google-like Autofill بهتر شده است.
- Do not re-prompt for فقط در صفحه Unlock و مربوط به درخواست دوباره Master Password است.
- Add Account روی سایت فعلی URL و عنوان پیشنهادی را از قبل پر می‌کند.
- Tag چندگانه، Import گروهی CSV/JSON و Site favicon اختیاری اضافه شده است.
- کنار New Password می‌توانید رمز قوی بسازید و فیلد Confirmation هم با همان رمز پر می‌شود.
- Dark mode و کنتراست متن‌ها اصلاح شده است.

Shared Vault همچنان اختیاری و فقط داخل Settings > تنظیمات پیشرفته است.
